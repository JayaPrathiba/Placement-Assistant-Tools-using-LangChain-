# 🎓 LangChain Placement Assistant

An AI-powered **Placement Assistant** built using **LangChain, Groq, Python, and Pandas**.

This project demonstrates how an LLM agent can use custom tools to interact with structured student data and answer placement-related questions in natural language.

---

## 🚀 Project Overview

The Placement Assistant allows users to ask questions about students using simple natural-language queries.

Instead of manually searching the student dataset, the LangChain agent decides which tool should be used and returns the relevant information.

### Example

```text
Ask something about the students:

"Find students with CGPA greater than 8.5"
